RatMath Library

JavaScript library for exact rational arithmetic using BigInt

Features Examples Playground API Installation

Key Features

🎯 Exact Arithmetic

No floating-point errors: every value is an exact BigInt fraction.

// JavaScript numbers
0.1 + 0.2 === 0.3              // false

// RatMath
R`0.1 + 0.2`.equals(R`0.3`)    // true

📊 Interval Arithmetic

Intervals carry exact bounds through every operation.

const a = R`1:2`
const b = R`0.5:1.5`
a.add(b)                       // 3/2:7/2
R`1:2 + 0.5:1.5`               // 3/2:7/2
R`1.5[+-0.01]`                 // 1.499:1.501

🔢 Type System

Results promote Integer → Rational → RationalInterval only as needed.

R`5 + 7`        // Integer 12
R`5 / 2`        // Rational 5/2
R`5 + 1:2`      // RationalInterval 6:7

🎨 RiX Notation

Literals inside R`…` are spelled as in the RiX language.

R`2..1/3`       // mixed: 7/3
R`0.#3`         // repeating: 1/3
R`3.~7~15~1`    // continued fraction: 355/113
R`2.5_^-2`      // radix shift: 1/40 (no E notation)
R`0xff.8`       // base prefix: 511/2

Basic Usage

R, sum, product, seq and range are in the next Core release after 0.6.0; this site uses that version.

import { R, Rational, sum } from '@ratmath/core';

const total = R`1/3 + 2/3`;              // Integer 1
const third = new Rational(1, 3);
R`${third} * 3`.equals(total);           // true
sum(1, 100, (i) => R`1/(${i}*(${i}+1))`); // 100/101

const measurement = R`5.2[+-0.05]`;      // 5.15:5.25
measurement.multiply(R`2`);              // 10.3:10.5
