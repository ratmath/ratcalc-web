JAVASCRIPT WITH EXACT ARITHMETIC

Input is JavaScript. The value of the last expression is shown; RatMath Core values are shown exactly (fraction, repeating decimal, interval). Declarations persist between inputs.

  • R`1/3 + 1/6` → 1/2 = 0.5
  • R`1:2 + 3` → 4:5 (intervals)
  • let x = R`2/3`, then R`${x}^2` → 4/9 = 0.#4
  • [1, 2, 3, 4].map(n => R`1/${n}`) → [1, 1/2, 1/3, 1/4]
  • new Rational(1, 7).toContinuedFractionString() → 0.~7
  • ans is the previous result; click a result to reuse it

INSIDE R`…`

  • Numbers: 3, -2, 3/4, 1..2/3 (mixed), 0.#3 (repeating), 1_000, 1.23[56:67] and 1.2[+-0.1] (uncertainty), 1.5? (certified prefix)
  • Operators: + - * /, ^ (integer powers), !, : (interval), parentheses
  • ${value} inserts a Core value, bigint, whole number or literal string without losing exactness

IN SCOPE

  • Core classes and parsers: Integer, Rational, RationalInterval, Fraction, parseNumber, parseInterval, BaseSystem, …
  • display("both" | "exact" | "decimal" | "mixed" | "cf"), digits(n)
  • vars(), clear(), help(), show(value)
  • Plain JavaScript numbers such as 0.1 + 0.2 are inexact and are labelled as such
  • No network access or imports: fetch, import() and similar are unavailable

INTERVAL VISUALIZATION

  • Click 📊 next to an interval result to plot it; drag endpoints, then “Save to Calculator”
  • ←/→ move a selected endpoint by the drag step; export as SVG or HTML

KEYBOARD

  • Enter runs the input; ↑/↓ step through history; Escape closes dialogs
