    JAVASCRIPT WITH EXACT ARITHMETIC

    Input is JavaScript. The value of the last expression is shown; RatMath Core values are shown exactly (fraction, repeating decimal, interval). Declarations persist between inputs, and ans is the previous result. Click a result to reuse it.

    • R`1/3 + 1/6` → 1/2 = 0.5
    • R`1:2 + 3` → 4:5 (intervals)
    • let x = R`2/3`, then R`${x}^2` → 4/9 = 0.#4
    • P = (x, y) => R`${x}^2 - ${y}`, then P(3, 4) → 5

    NUMBERS INSIDE R`…` (RiX SPELLING)

    • 3/4, 1..2/3 (mixed), 0.#3 (repeating), 1_000, 2:5 (interval)
    • 1.2[3:6] → 1.23:1.26, 1.5[+-0.01] → 1.499:1.501 (uncertainty; RiX needs :)
    • 3.~7~15~1 → 355/113 (continued fraction)
    • 1_^3 → 1000, 2.5_^-2 → 1/40 (radix shift; there is no E notation)
    • 0xff.8 → 511/2, 0b0.#01 → 1/3, 0z[7]66 → 48 (base prefixes); R.base(16)`ff.8 / 3` reads plain digits in base 16
    • Operators: + - * /, ^ and ** (integer powers), !, !!, : (interval), parentheses; ${value} inserts a value exactly

    SUMS, PRODUCTS AND SEQUENCES

    • sum(1, 10, i => R`${i}^2`) → 385 (was SUM[i](i^2,1,10))
    • product(1, 5, j => j) → 120; seq(0, 6, 2, k => R`${k}^3`) → [0, 8, 64, 216]
    • sum([R`1/2`, R`1/3`]) → 5/6; range(0, 1, R`1/4`) → [0, 1/4, 1/2, 3/4, 1]
    • range and seq return lists with exact methods: xs = range(1, 4), xs.sum() → 10, xs.multiply(R`1/2`) → [1/2, 1, 3/2, 2], xs.pow(-1).sum() → 25/12, xs.max(); help(xs) lists them

    CERTIFIED FUNCTIONS: A (@RATMATH/ANALYTIC)

    Every answer is an interval proven to contain the true value (30 digits). Long intervals display rounded outward, e.g. 1.2[3:6] = 1.23:1.26; display("exact") shows the exact endpoints. Type help("analytic") for the full list.

    • A.exp(R`1/3`) → 1.39561242508608952862812531960[2:3]; also A.log, log1p, sqrt, sin, cos, tan, atan, sinh, cosh, tanh, A.pi, A.e
    • A.sin(R`-1:1`) → about ±0.8414709848: the true range, not the naive ±1.18
    • B = analytic({ digits: 60 }), then B.atan(R`1/5`): another precision
    • m = A.model(x => A.exp(A.sin(x)), R`0:1`): a Taylor model (exact polynomial + certified remainder on [0, 1]); then m.at(R`1/3`), m.range(), m.integral(), m.describe(), m.coefficients. Inside, x is a model: use .add, .multiply, .divide, .negate, .pow(n)
    • A.integral(x => A.exp(A.sin(x)), 0, 1) → 1.631869608418051[16…:53…]; A.range(x => x.multiply(A.cos(x)), R`0:3`)
    • A.series(R`-1/2:1/2`, { centre: 0, coefficient: k => R`1/2^${k}`, rule: "ratio", q: R`1/4` }): your own power series with a tail rule ("lagrange", "ratio", "alternating", "explicit")
    • A.log(R`0:1`) → AnalyticError with the reason: failed hypotheses never give unproven values

    DISPLAY

    • display("both" | "exact" | "decimal" | "mixed" | "cf" | "sci") for every result (was DECI, RAT, BOTH, MIX, CF, SCI)
    • digits(n) decimal digits, sciDigits(n) significant digits (was LIMIT, SCIPREC)
    • One value: cf(x), mix(x), deci(x, 40), sci(x, 6) → e.g. 1.6667_^-1…

    BASES

    • hex(), bin(), oct(), base(7), base("0123456789ab") also show every result in that base, e.g. 0xff = 255; dec() stops
    • One value: hex(R`255`) → 0xff, bin(R`1/3`) → 0b0.#01, inBase(R`1:2`, 2) → 0b1:0b10
    • Base text uses RiX prefixes, so R`0x1.#5` reads it back

    CONTINUED FRACTIONS AND APPROXIMATION

    • R`355/113`.toContinuedFraction() → [3, 7, 16]; cf(R`355/113`) → 3.~7~16
    • R`355/113`.convergents() → [3, 22/7, 355/113]; getConvergent(n)
    • R`314159/100000`.bestApproximation(100) → 311/99; also bestConvergent(n)
    • Rational.fromContinuedFraction([3, 7, 15, 1]) → 355/113

    WHAT A VALUE CAN DO

    • help(x) lists a value's methods with examples, e.g. help(R`355/113`)
    • Integer: gcd, lcm, factorial, floorDivide, divmod, toBase, …
    • Rational: numerator, denominator, floor, round, toMixedString, toRepeatingBase, …
    • Interval: low, high, midpoint, mediant, shortestDecimal, mpow (old **), …
    • Plain JavaScript numbers such as 0.1 + 0.2 are inexact and are labelled as such
    • No network access or imports: fetch, import() and similar are unavailable
